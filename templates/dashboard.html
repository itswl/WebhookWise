Why didn't I get notified? — the suppression stack
Every alert passes the same gates, in order: ① ingress backpressure (per-alert storms / queue high-water, opt-in) → ② dedup (repeats join an existing thread) → ③ smart noise reduction (derived alerts of one root cause) → ④ silences and maintenance windows (operator mutes) → ⑤ flapping mute (rapid firing↔recovered oscillation, opt-in) → ⑥ cooldown (just notified) → ⑦ forwarding rules (no matching rule, no delivery) → ⑧ periodic reminder policy. Each trace row below names the exact gate that stopped (or forwarded) the alert.
